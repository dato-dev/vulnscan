# Единственное место, где записаны версии SDK наблюдаемости.
#
# Было семь: pyproject плюс шесть Dockerfile, и во всех через `>=`. Это значит,
# что каждая пересборка образа могла притащить другую версию, а какая именно
# работает на стенде — выяснялось бы по `pip freeze` внутри контейнера. Для
# библиотек, формирующих трейсы и метрики, это особенно скверно: расхождение
# версий проявляется не ошибкой, а изменившимися именами атрибутов.
#
# Поэтому точные версии, а не нижние границы. Обновление — осознанное действие:
# правится этот файл, пересобираются образы, проверяется, что спаны и метрики
# на месте.
#
# Проверяется тестом `tests/test_metrics_contract.py`: Dockerfile не имеет права
# называть версию сам.
