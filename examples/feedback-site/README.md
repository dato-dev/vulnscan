# Форма обратной связи — пример подключения

Работающая иллюстрация к [docs/integration.md](../../docs/integration.md):
сайт с формой, куда посетитель прикладывает PDF, а сайт проверяет его сканером.

## Как устроено

```
браузер ──файл──> этот сайт ──подпись ключом──> сканер
                      ↓
              пересобранная копия
```

Ключ живёт **на сервере сайта**, а не в браузере: положить его в JavaScript
нельзя, а без подписи сканер запрос не примет.

Плата за простоту — враждебный файл на секунду оказывается в памяти этого
процесса. Для демонстрации это приемлемо. В бою стоит смотреть в сторону
одноразовых талонов на загрузку, чтобы файл шёл сразу в сканер, минуя сайт;
см. «Интеграция с формами обратной связи» в [docs/ideas.md](../../docs/ideas.md).

## Запуск

Нужен ключ. Выпустить можно через административную ручку сканера либо вписать
запись в `deploy/config/keys.json`:

```json
{
  "demo-site-1": {
    "tenant": "demo-site",
    "secret": "СГЕНЕРИРУЙТЕ: python3 -c \"import secrets; print(secrets.token_urlsafe(32))\"",
    "callback_hosts": []
  }
}
```

`callback_hosts` пуст намеренно: у сайта нет публичного адреса, принимать
коллбэк ему некуда, а разрешать их «на всякий случай» — лишняя поверхность.
Результат забирается опросом, как описано в §4 руководства.

Затем:

```
docker compose --profile demo up -d
```

Сайт поднимется на `http://localhost:8000`.

## Что показывает

Три исхода, и средний важнее остальных:

| Вердикт | Что делает сайт |
|---|---|
| `malicious` | отклоняет вложение, показывает признаки |
| `unsupported`, `encrypted`, незнакомый | **не принимает как чистое** — просит другой файл |
| `clean` | принимает и отдаёт **пересобранную копию**, а не оригинал |
| не успели проверить | честно говорит, что проверка идёт, и просит повторить |

Последняя строка — отдельная ловушка, в которую я сам сначала и попал. Когда
проверка не укладывается в отведённое время, сервис отвечает `202`, и наивный
код показывает посетителю «файл вызвал вопросы». Но «не закончили» и
«подозрительный» — разные вещи, и путать их так же скверно, как считать
непроверенное чистым.

Средняя строка — самая частая ошибка интеграции. `not blocked` не означает
«безопасно»: файл, который не удалось проверить, не заблокирован, но и чистым
не является. Проверка `if not blocked` молча приняла бы зашифрованный архив.

Последняя строка — про то, ради чего всё и затевалось. Даже чистый файл
отдаётся пересобранным: копия собрана заново, без активных элементов, и это
работает против того, чего мы ещё не умеем детектить.
